# Physics & Embodied AI

具身智能与物理法则：语料级分析报告与配套产物。

## 概览 / Overview

本仓库发布《具身智能与物理法则：影响尺度与安全约束分析报告》及其配套语料产物。报告基于一个具身智能安全语料库（具身域检索 1,349 篇，核心相关 377 篇，核心集 17 篇全文深读），回答两个问题：

1. 具身智能受真实世界物理法则影响大吗？
2. 其安全性受物理法则制约有哪些、有多大影响？

报告按八类物理约束（光学 / 电磁 / 声学 / 时空实时性 / 动力学与控制 / 物理不可逆性 / 能量材料与作业 / sim-to-real）逐项列举实例与物理联系，并给出量化证据总表（17 行）。
